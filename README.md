# MPLS Service Provider Lab

## 📌 Overview

This project is a structured implementation of a real-world ISP (Internet Service Provider) network using MPLS technology. The lab is designed to simulate industry-level network architecture including core, edge, and customer layers.

---

## 🧠 Objectives

* Understand service provider network architecture
* Implement MPLS forwarding using LDP
* Design scalable MP-BGP using Route Reflector
* Deploy L3VPN using VRF
* Simulate real-world ISP traffic flow
